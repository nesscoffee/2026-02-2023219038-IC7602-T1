# Guia de instalacion

### Este documento brevemente explicara como instalar y correr el codigo


Es muy sencillo, primero se ocupa de requisito instalado

- NodeJS

Ya una vez se cumple con esto se corre el comando siguiente

- npm install

Con esto definido se puede correr el programa con

- npm run dev

Finalmente le dara el link en localhost para ver el programa

localhost:5173

usualmente es ese a no ser que el puerto este ocupado, en caso de ser asi, le dara un puerto distinto
